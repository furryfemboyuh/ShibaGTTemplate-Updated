# ShibaGTTemplate-Updated

An updated version of the ShibaGT Mod Menu template for GorillaTag VR.

## Installation

1. Download or clone the repository.
2. Download the **Source Code (ZIP)** from the repository and extract it.
3. Open the extracted source folder.
4. Locate `gamepath.txt`.
5. If necessary, edit `gamepath.txt` to point to your Gorilla Tag installation directory.
6. Open the project in Visual Studio and build it.

## Configuration

### `gamepath.txt`

This file contains the path to your Gorilla Tag installation.

If your game is installed in a non-default location, update the path inside `gamepath.txt` to match your installation.

Make sure the path points to the correct Gorilla Tag directory.
